# 晓萌（Xbot）

晓萌作为一个家政机器人，由视觉、语音、导航、状态机、机械臂等模块组成。通过利用这些模块实现复杂的功能。下面将针对机械臂模块进行详细介绍。

## 机械臂物理结构介绍

### 机械臂结构

机械臂结构包括：滑台（包括驱动电机和滑杆），机械臂平台（连接机械臂和滑台），机械臂（由关节和连杆组成），夹爪（末端执行器）。

## 机械臂控制软件模块

### 机械臂信息处理模块

机械臂信息处理模块用于实现对机械臂各个关节角度等信息的获取和处理。

### 机械臂数据包模块

机械臂数据包模块用于封装机械臂的数据信息，方便传输和处理。

### 机械臂通信模块

机械臂通信实现机械臂模块与电子（下位机）之间的通信，包括数据的发送和接收。

### 机械臂解算函数模块

机械臂解算函数模块实现对自定义解算器（函数）的调用，计算机械臂的关节角度，从而实现机械臂的运动。
